Title: Contoso Traders - Memorial Day Sale + Core Feature Validation

As a shopper visiting the Contoso Traders e-commerce application
I want to see the Memorial Day Sale promotion and use all key features
So that I can discover deals and make purchases with confidence

Acceptance Criteria:

AC-001: The application top banner should display a Memorial Day Sale banner.
AC-002: The home page hero section should display featured products or a promotional banner.
AC-003: The site header should display the Contoso Traders logo and brand name.
AC-004: The top navigation should list product categories such as Controllers, Laptops, and Headphones.
AC-005: Users should be able to type a search query into the search box and see results.
AC-006: The products listing page should display product cards with images, names, and prices.
AC-007: Clicking a product card should navigate to the product detail page for that product.
AC-008: The product detail page should display the product name, price, and an Add to Cart button.
AC-009: The cart icon in the header should be visible and clickable.
AC-010: The footer should be visible at the bottom of the page with site information.
